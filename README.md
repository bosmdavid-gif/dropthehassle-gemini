# DropTheHassle for Gemini CLI

Put your site online from Gemini CLI. Your AI publishes it on a free link with HTTPS. No account and no token needed to start.

Want your own name? A .com is €19 / $19 a year, the same every year. You buy it yourself in the dashboard. Your AI can look up names but can never pay.

Got a server part too? Keep it on AWS, Google Cloud, DigitalOcean or your own server, and your AI links it to your site in one step.

## Install

```
gemini extensions install https://github.com/bosmdavid-gif/dropthehassle-gemini
```

Then ask: "put my site online".

## What it adds

- The DropTheHassle MCP server at https://dropthehassle.com/mcp
- A short GEMINI.md so Gemini knows the steps: publish, give you the live link and the claim link, never pay.
